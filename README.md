# Online Store

A modern e-commerce web application built with React, featuring product browsing, shopping functionality, and responsive design.

## Description

This is a full-featured online store application that provides users with an intuitive shopping experience. The application includes product listings, detailed product pages, user account management, and various informational pages.

## Features

- Product catalog with multiple product pages
- Responsive navigation and routing
- User account management
- About and Contact pages
- Partner information section
- New arrivals showcase
- Smooth animations and transitions
- Mobile-friendly design

## Technologies Used

- React 18.2.0
- React Router DOM 6.11.2
- GSAP (GreenSock Animation Platform) 3.11.5
- React Icons 4.8.0
- React Scroll 1.8.9

## Installation

1. Clone the repository:
```bash
git clone <repository-url>
cd Online-Store
```

2. Install dependencies:
```bash
npm install
```

3. Start the development server:
```bash
npm start
```

The application will open in your browser at `http://localhost:3000`

## Available Scripts

### `npm start`
Runs the app in development mode.

### `npm build`
Builds the app for production to the `build` folder.

### `npm test`
Launches the test runner in interactive watch mode.

### `npm eject`
Ejects from Create React App configuration (one-way operation).

## Pages
